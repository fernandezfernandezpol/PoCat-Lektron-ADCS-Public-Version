AirCoreTorquerModel:

 Draw an air core magnetic torquer.

 Type AirCoreTorquerModel for a demo.
--------------------------------------------------------------------------
   Form:
   [v, f] = AirCoreTorquerModel( nTurns, rWire, dims )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   nTurns      (1,1) Wire turns
   rWire       (1,1) Wire radius (m) 
   dim         (1,2) Dimensions of the coil (m)

   -------
   Outputs
   -------
   v           (:,3) Vertices
   f           (:,3) Faces

--------------------------------------------------------------------------
