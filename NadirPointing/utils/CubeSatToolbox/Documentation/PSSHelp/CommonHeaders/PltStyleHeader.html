PltStyle:

--------------------------------------------------------------------------
   Edit this to globally change the plot styles for the plot labels

   Since version 1.
--------------------------------------------------------------------------
   Form:
   [style, font, fSI] = PltStyle()
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   none

   -------
   Outputs
   -------
   style     Font style
   font      Font
   fSI       Font size increase (above default size)

--------------------------------------------------------------------------
