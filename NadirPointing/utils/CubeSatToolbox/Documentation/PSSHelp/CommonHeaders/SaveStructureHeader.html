SaveStructure:

   Save a structure in a file. You will be able to read it in by typing
   g = load('fileName');
--------------------------------------------------------------------------
   Form:
   SaveStructure( g, fileName )
--------------------------------------------------------------------------

   ------
   Inputs
   ------

   g        (:)   Structure
   fileName (1,:) .mat file name

   -------
   Outputs
   -------
   None
