XLabelS:

--------------------------------------------------------------------------
   Creates an xlabel using the toolbox style settings
   x can be entered as 'text@fontName' to get a different font.

   Since version 1.
--------------------------------------------------------------------------
   Form:
   XLabelS( x, font )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x          (:)    Text
   font       (1,:)  Font name

   -------
   Outputs
   -------
   None

--------------------------------------------------------------------------

Common: General/DeBlankLT
Common: Graphics/PltStyle
