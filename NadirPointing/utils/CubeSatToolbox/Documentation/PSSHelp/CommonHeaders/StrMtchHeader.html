StrMtch:

--------------------------------------------------------------------------
   In a matrix with each row a string finds the matching string

   Since version 1.
--------------------------------------------------------------------------
   Form:
   k = StrMtch( s, sM )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   s                   String
   sM                  Strings to test

   -------
   Outputs
   -------
   k                   Row index for matching string

--------------------------------------------------------------------------
