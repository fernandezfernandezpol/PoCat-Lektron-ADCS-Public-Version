DeBlankAll:

--------------------------------------------------------------------------
   Delete all blanks including spaces, new lines, carriage returns,
   tabs, vertical tabs, and formfeeds.
--------------------------------------------------------------------------
   Form:
   s = DeBlankAll( s )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   s      (1,:)   Character string

   -------
   Outputs
   -------
   s      (1,:)   Character string

--------------------------------------------------------------------------
