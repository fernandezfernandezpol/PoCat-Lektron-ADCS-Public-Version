NormalizationMatrix:

 Generate a normalization matrix for spherical harmonics
 c unnormalized * f = c normalized
 s unnormalized * f = s normalized
 p normalized   = p unnormalized / f
--------------------------------------------------------------------------
   Form:
   f = NormalizationMatrix( nN, nM )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   nN	(1,1)  Rows
   nN 	(1,1)  Columns

   -------
   Outputs
   -------
   f	(nN,mM)   State derivatives 

--------------------------------------------------------------------------
