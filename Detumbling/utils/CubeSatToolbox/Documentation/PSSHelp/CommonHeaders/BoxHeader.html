Box:

--------------------------------------------------------------------------
   Draw a box centered at the origin.
   The open face is a character string
   -x, +x, -y, +y, -z, +z

   Type Box for a demo.
--------------------------------------------------------------------------
   Form:
   [v, f] = Box( x, y, z, openFace )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   x           (1,1)  x length
   y           (1,1)  y length
   z           (1,1)  z length
   openFace    (1,2)  Which face is open (optional)
   

   -------
   Outputs
   -------
   v           ( 8,3) Vertices
   f           (12,3) Faces

--------------------------------------------------------------------------
