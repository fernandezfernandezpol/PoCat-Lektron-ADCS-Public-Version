JDToDateString:

--------------------------------------------------------------------------
   Convert Julian Date to the form '04/20/2000 00:00:00'
  
   Typing JDToDateString returns the current date.
--------------------------------------------------------------------------
   Form:
    s = JDToDateString( jD )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   jD            (1,1)   Julian Date   

   -------
   Outputs
   -------
   s             (1,:)   String 'mm/dd/yyyy hh:mm:ss'

--------------------------------------------------------------------------

Children:

Common: Time/Date2JD
Common: Time/JD2Date
