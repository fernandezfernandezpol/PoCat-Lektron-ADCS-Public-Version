DeBlankLT:

--------------------------------------------------------------------------
   Delete leading and trailing blanks.

   Since version 3.
--------------------------------------------------------------------------
   Form:
   s = DeBlankLT( s )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   s      (1,:)   Character string or cell array

   -------
   Outputs
   -------
   s      (1,:)   Character string or cell array

--------------------------------------------------------------------------
