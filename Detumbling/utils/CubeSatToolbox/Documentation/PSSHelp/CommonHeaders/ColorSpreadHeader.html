ColorSpread:

--------------------------------------------------------------------------
   Produce a set of 3-element RGB colors that spread across the colormap.

   Since version 8.
--------------------------------------------------------------------------
   Form:
   colors = ColorSpread( n )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   n             (1,1)    Number of colors to produce

   -------
   Outputs
   -------
   colors        (n,3)    n rows of colors

--------------------------------------------------------------------------
