Axis3D:

--------------------------------------------------------------------------
   Adjust 3D axes.

   Axis3D is the same as Axis3D('equal')

   Since version 1.
--------------------------------------------------------------------------
   Form:
   Axis3D( s )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   s                 String 'equal' is the only option available

   -------
   Outputs
   -------
   None

--------------------------------------------------------------------------
