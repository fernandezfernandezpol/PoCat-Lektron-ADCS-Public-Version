LoadEarthMap:

--------------------------------------------------------------------------
   Creates a figure with Earth texturemap, political boundaries, and lat/lon.
   Loads the file EarthMapData.mat

   Since version 10.
--------------------------------------------------------------------------
   Form:
   h = LoadEarthMap( name )
--------------------------------------------------------------------------

   ------
   Inputs
   ------
   name       (1,:) Figure title

   -------
   Outputs
   -------
   h           Handle to the figure

--------------------------------------------------------------------------

Children:

Common: General/Watermark
